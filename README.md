## Sandro Cunha

Full-stack developer and founder of Rhuma RH, an HR-tech company serving
food service businesses in Brazil. Nine years running restaurant operations
before that — I build software for problems I lived.

**Stack:** React · Next.js · TypeScript · Node.js · Prisma · PostgreSQL · Tailwind

### What I build

**ERP RhumaRH** — Multi-tenant HR and payroll system used daily by
consultancies managing multiple clients. Role-based access across five roles,
full tenant isolation enforced by a cascading authorization layer,
40+ REST API routes. Next.js, React, TypeScript, Node, Prisma, PostgreSQL.

**Rhuma Play** — Gamification platform for corporate events. Live ranking,
multi-campaign support, metrics dashboards with CSV and PDF export,
token-based monitor access with isolation enforced at the SQL level.
React, Vite, Supabase.

**Portal de Contracheque** — Payslip portal for food service employees.
Login by CPF, PDF generation, deployed on Vercel.
Next.js, TypeScript, Prisma.

**CheckList App** — Operational checklist tool for restaurant teams.
